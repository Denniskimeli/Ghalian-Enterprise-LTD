# Kimeli Timber Suppliers — Website

A responsive HTML/CSS/JavaScript website based on the generated Kimeli Timber Suppliers homepage mockup.

## Open in VS Code

1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Open `index.html` directly in a browser, or use the **Live Server** extension in VS Code.
4. Edit `css/style.css` for colours, spacing, typography and responsive styling.
5. Edit `index.html` for text, prices, products, contact details and sections.
6. Replace images inside `assets/` with your real timber/product photography.

## Important placeholders

The generated mockup contained example contact details and illustrative Pine/Mukima pricing. The code therefore leaves Pine and Mukima as **Price on request** and marks the contact/location information for replacement with your actual business details.

The map currently points to the general Ruiru area and should be changed to your exact business location.
